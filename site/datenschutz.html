Hosting und Server-Logfiles

Diese Website ist eine statische Seite. Sie wird auf einem eigenen Server mit dem Webserver nginx betrieben und zusätzlich über GitHub Pages bereitgestellt, einen Dienst der GitHub Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA.

Bei jedem Aufruf speichert der jeweilige Server automatisch technische Zugriffsdaten in Logfiles: IP-Adresse, Datum und Uhrzeit, aufgerufene Adresse, HTTP-Statuscode, übertragene Datenmenge, Referrer und User-Agent (Browser und Betriebssystem). Die Logfiles werden nur so lange aufbewahrt, wie es für den sicheren Betrieb erforderlich ist, und anschließend gelöscht.

Bei Aufruf über GitHub Pages verarbeitet GitHub diese Daten auch in den USA. Die Übermittlung stützt sich auf das EU-US Data Privacy Framework. Details stehen in der Datenschutzerklärung von GitHub.

Die Verarbeitung erfolgt auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO. Das berechtigte Interesse liegt im sicheren und stabilen Betrieb der Website.

Keine Cookies, kein Tracking

Diese Website setzt keine Cookies und verwendet keine Analyse- oder Tracking-Werkzeuge.

Keine externen Ressourcen

Schriftarten und Bilder werden vom selben Server wie die Website ausgeliefert. Beim Aufruf der Website werden keine Inhalte von Drittanbietern geladen.

Lokale Speicherung der Sprachwahl

Wenn Sie die Sprache umschalten, wird Ihre Auswahl im lokalen Speicher (localStorage) Ihres Browsers abgelegt. Diese Information verbleibt in Ihrem Browser, wird nicht an den Server übertragen und kann jederzeit über die Browsereinstellungen gelöscht werden.

Externe Links

Die Links zu GitHub, LinkedIn und zum Blog führen zu externen Angeboten. Daten werden erst dann an den jeweiligen Anbieter übertragen, wenn Sie einen Link anklicken. Dort gilt die Datenschutzerklärung des jeweiligen Anbieters.
